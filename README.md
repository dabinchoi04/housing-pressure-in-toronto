# Housing Pressure in Toronto

An interactive data visualization project examining housing affordability and housing pressure across Toronto neighbourhoods.

## Project Overview

This project investigates the question:

**Where is housing pressure worst in Toronto, and how does it vary at the neighbourhood level?**

The dashboard combines shelter costs, housing program trends, home-price context, and income composition to compare housing conditions across Toronto.

## Dashboard

The interactive dashboard contains five visualizations:

1. Housing pressure map
2. Shelter cost comparison
3. Housing programs over time
4. Home prices and highrise population
5. Income composition by region
